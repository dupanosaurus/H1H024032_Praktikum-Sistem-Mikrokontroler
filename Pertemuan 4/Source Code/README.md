## Percobaan 1
Program ini menggunakan library Servo.h untuk mengendalikan motor servo dengan masukan dari potensiometer. Pin analog A0 dipakai untuk membaca tegangan potensiometer, sedangkan pin digital 9 digunakan sebagai jalur sinyal servo. Pada bagian setup(), servo dihubungkan ke pin yang telah ditentukan melalui myservo.attach() dan komunikasi serial diaktifkan dengan baud rate 9600 untuk monitoring data. Di dalam loop(), Arduino membaca nilai potensiometer menggunakan analogRead() dalam rentang 0–1023, lalu nilai tersebut diubah dengan fungsi map() menjadi sudut servo 0° hingga 180°. Nilai sudut hasil konversi kemudian dikirim ke servo menggunakan myservo.write(). Selain itu, nilai ADC dan sudut servo ditampilkan pada Serial Monitor. Delay singkat diberikan agar pergerakan servo lebih stabil dan halus.

## Percobaan 2
Program ini memanfaatkan potensiometer sebagai input analog untuk mengatur kecerahan LED melalui sinyal PWM. Potensiometer dihubungkan ke pin analog A0, sedangkan LED dipasang pada pin digital 9 yang mendukung PWM. Pada setup(), pin LED diatur sebagai output dan komunikasi serial diaktifkan pada baud rate 9600. Di dalam loop(), Arduino membaca nilai potensiometer dengan analogRead() pada rentang 0–1023. Nilai tersebut kemudian dikonversi menggunakan fungsi map() menjadi rentang PWM 0–255. Selanjutnya, nilai PWM dikirim ke LED menggunakan analogWrite() sehingga tingkat kecerahan LED berubah sesuai posisi potensiometer. Data ADC dan PWM juga ditampilkan pada Serial Monitor, sedangkan delay digunakan agar pembacaan lebih stabil dan tampilan data tidak terlalu cepat.

## Soal 1
Program pada soal pertama merupakan modifikasi dari percobaan servo, di mana rentang gerak servo dibatasi hanya dari 30° sampai 150°. Potensiometer tetap dibaca menggunakan analogRead() dengan rentang ADC 0–1023 melalui pin A0. Nilai ADC tersebut kemudian dikonversi menggunakan fungsi map() menjadi sudut servo 30°–150°, sehingga servo tidak bergerak ke posisi ekstrem 0° atau 180°. Hasil konversi sudut dikirim ke servo melalui myservo.write(pos). Nilai ADC dan sudut servo ditampilkan pada Serial Monitor untuk memudahkan pengamatan selama praktikum. Delay 15 milidetik diberikan agar gerakan servo lebih halus dan responsif.

## Soal 2
Program pada soal kedua merupakan modifikasi pengaturan LED PWM agar LED hanya menyala pada rentang kecerahan sedang. Potensiometer dibaca melalui pin analog A0 menggunakan analogRead(), kemudian nilainya diubah ke rentang PWM 0–255 menggunakan fungsi map(). Setelah itu, program menggunakan percabangan if untuk memeriksa nilai PWM. Jika nilai PWM berada pada rentang 50 sampai 200, maka LED dinyalakan sesuai nilai PWM menggunakan analogWrite(). Jika nilai PWM di bawah 50 atau di atas 200, LED dimatikan dengan nilai PWM 0. Nilai ADC dan PWM tetap ditampilkan pada Serial Monitor sebagai data monitoring, sedangkan delay 50 milidetik digunakan untuk menjaga kestabilan pembacaan.
